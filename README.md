README.md-健身打卡助手
​

## 1,项目用途

针对专业健身人群和普通运动爱好者，可以让用户在没有广告，没有任何收费的网页里知道自己在健身的过程里饮水量是否达标，运动消耗量和饮食摄入热量以及蛋白质含量
- 专业健身人群：按克数精确记录饮食，关注蛋白质和运动消耗。
​- 普通运动爱好者：按份数快速估算，降低记录门槛。
​

## 主要功能

1-本地账号与人群模式
​- 手机号 + 密码登录、短信验证码登录（演示码直接显示在页面上）、注册、重置密码。
​- 「专业健身人群 / 普通运动爱好者」两套模式，饮食录入方式和每日数据独立保存。

2- 每日打卡总览
​- 饮水、运动、饮食三类目标完成度圆环，达标后可完成当日打卡并发放奖励动画。
​- 连续打卡天数、今日总消耗（基础代谢 + 运动净消耗）。

3- 饮水 / 运动 / 饮食记录
​- 饮水：+250ml、+500ml、自定义、撤销，目标 2000ml。
​- 运动：20 个常见项目快捷选择，也支持自定义，但对于猎奇运动项目不可以自定义添加；按 MET 估算消耗，逐项勾选完成。
​- 饮食：内置常见食物热量/蛋白质库；专业模式按克数，普通模式按份数；超出摄入热量则打卡不成功。

4- 睡眠记录
​- 录入入睡时间、起床时间、半夜清醒时长。
- 自动计算实际睡眠时长并给出「良好 / 睡眠不足」评价。
​- 睡眠不足时提示「睡眠偏少，高强度运动容易头晕乏力」，当天有高强度运动时给出降强度建议；睡眠充足时触发月亮表扬动画。

5- 个人档案与身体数据台账
​- 点击顶部带手机号的个人入口，查看身高、体重、年龄、性别。
​- 一键计算 BMI，给出偏瘦 / 健康 / 超重 / 肥胖评价与简单建议，并结合最近腰围提示腹型肥胖风险。
​- 身体数据台账记录体重、腰围，每次录入自动生成体重变化折线图，可删除记录。

6- 运动数据可视化与导出
​- 运动总时长统计为柱状图。
​-体重变化折线图（读取身体数据台账）。
​- 导出打卡记录为 .txt：包含两种人群的饮水、运动、饮食、睡眠、打卡状态和身体数据台账，方便用户使用回顾往日数据。

7-历史与外观
​- 近 7 天记录、近 3 个月历史明细。
​- 5 套皮肤（粉色 / 黑白 / 绿色 / 蓝色 / 赛博）+ 夜间模式；夜间模式下皮肤名称使用对应亮色。

## 合成数据说明
仓库和页面**不包含任何真实用户数据**。截图和演示使用的都是合成数据：
- 账号：`13800138000`，仅用于本地演示。
- 运动、饮食、饮水、睡眠记录均为虚构，用于展示图表和提示。
- 所有数据只写入当前浏览器的 `localStorage`，不会上传到任何服务器。


## 已知问题
-  **纯本地存储**：换设备、换浏览器、清理浏览器数据都会丢失记录，没有云端同步和备份；导出的 `.txt` 只能阅读，暂不支持重新导入。
-  **账号体系是演示级**：手机号、密码、验证码都在前端处理，没有服务端校验，不能用于生产环境；纯前端创作：没有后端，无法通过电话号码接收验证码。
-  **BMI 与睡眠是估算**：BMI 只反映体重与身高的关系，无法代替精确的体脂率，仅供参考；睡眠周期按 90 分钟粗略估算，评价和建议仅供参考，不构成医疗建议。
-  **图表范围有限**：只支持本周 / 本月，且运动数据按当前人群类型统计；暂不支持自定义日期区间和多种运动类型对比。
- **无法接入硬件**：目前无法接入运动手表，其他健身APP，体重秤等等硬件。
